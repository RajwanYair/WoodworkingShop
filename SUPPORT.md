# Support

WoodworkingShop is a free, open-source project maintained by volunteers. Community support is provided on a best-effort basis; there is no paid support or response-time guarantee.

## Questions and usage help

- Start with the [User Guide](docs/USER-GUIDE.md) and [Troubleshooting](README.md#troubleshooting).
- Ask usage questions or share project ideas in [GitHub Discussions](https://github.com/RajwanYair/WoodworkingShop/discussions).
- Try the [live demo](https://rajwanyair.github.io/WoodworkingShop/) to confirm whether an issue also occurs in the deployed app.

## Report a problem

Use the [bug report form](https://github.com/RajwanYair/WoodworkingShop/issues/new?template=bug_report.yml) for reproducible defects. Include the browser and operating system, steps to reproduce, expected and actual results, and screenshots or a minimal project file when safe to share. Remove personal or sensitive information before attaching files.

For a feature request, use the [feature request form](https://github.com/RajwanYair/WoodworkingShop/issues/new?template=feature_request.yml). Check the [changelog](CHANGELOG.md) and existing issues first so reports can be linked to any existing work.

## Security concerns

Do not post security vulnerabilities in public issues or discussions. Follow the private reporting instructions in [SECURITY.md](.github/SECURITY.md).

## Releases and availability

The application runs in your browser and does not require an account. Check the [live demo](https://rajwanyair.github.io/WoodworkingShop/) and [GitHub Actions](https://github.com/RajwanYair/WoodworkingShop/actions) for deployment and release status. Source code and release history are available in the [repository](https://github.com/RajwanYair/WoodworkingShop) and [changelog](CHANGELOG.md).
